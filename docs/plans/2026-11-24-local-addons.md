# 正式版上的本机增补

- 日期：2026-11-24
- 上游基线：DS-Bot `0.3.10`，提交 `d104d9ca18d69a35460f14e15dff4d553181433a`。
- 本地分支：`feat/stable-addons`。不跟随 `dev` 或滚动 `main`；后续只在明确选择的新正式 Release 上核对接入点。

## 约束

新逻辑放独立增补文件，现有文件仅保留必要的导入、调用和界面插入点。不修改 DSH、不绕过其权限与配对接口、不改依赖版本。接入清单和兼容性检查必须能区分原版基线变化与增补缺失。

## 功能契约

### 消息模式

每 Bot 可选择 `queue` 或 `steer`；未单独设置时尊重基础发送设置。`queue` 等当前工作结束，`steer` 使用公开的插话接口，不要求用户再点队列的 `↑`。用户消息模式不得改写 Bot 之间的投递、定时消息或审批答复。已排队的历史消息不因切换设置被全部自动发送。

### 过期会话

仅处理最后活动超过 24 小时的已结束后台会话和旧会话段。保留会话记录、任务记录和搜索／历史读取。正在运行、等审批、有待发送消息、正在切段／交接、有活跃后台作业的会话，以及当前私聊和群成员的当前段均不处理。

归档调用 DSH 公开接口；历史读取不得为了展示工具和任务详情重新加载整份旧 Agent。增补缓存必须有容量上限。DSH 底层对象回收和实际内存变化需实机验收，不把单独的归档标记当作已释放内存的证据。

### 远程权限

电脑本机先开启授权开关，手机再开启本地管理开关。默认关闭。仅已配对的手机权限设备可修改 Bot／群权限预设；浏览器权限不因客户端名字或新增设置提权。保留原生解锁及完全权限确认。电脑授权开关不能由远程请求修改，也不能通过其他设置接口绕过。

### 工具与任务

聊天显示当前工具原名、运行与结果状态；工具列表可展开并按需查看脱敏参数、输出和错误。大输出分页，详情关闭后不常驻完整日志。工具文本不作为代码或 HTML 执行，密钥及认证字段不回显。

手机补齐真实后台任务和待办入口，区分后台任务、群共享待办与工具待办／计划。状态必须来自服务器，不根据普通聊天文字猜测任务完成。不以增加手机展示为由允许浏览器读取原本禁止的 Agent 会话。

### 客户端名称

配对设备列表优先显示已保存的名称，空名称回退到手机／网页浏览器类别。已配对设备仅在原公钥验证成功后刷新名称；保留设备 ID、公钥、配对日期、权限类别和撤销行为。`DSBotDeck（Windows）` 是显示名称，不是授权凭证，不新增 `desktop` 权限类别。

## 验证与交付

本机只进行静态核对，不执行安装、构建、程序运行或测试。准备针对消息模式、归档边界、远程授权、工具脱敏分页、任务展示、名称刷新和兼容性检查的回归用例，由用户执行。

`ds-bot/client.js` 和 `ds-bot/link.js` 是生成产物，不手工编辑。源码增补后须按原构建流程重新生成，再构建桌面／手机；直接复制源码到已安装程序不会自动生效。原版正式提交与增补分支应分别验证，以隔离上游、环境和增补问题。
