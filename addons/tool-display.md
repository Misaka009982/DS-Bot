# 工具记录的三层展开

此修正从增补 1.2.0 提供，针对 DS-Bot 插件原生聊天与共用工具详情组件；旧版 1.1.0 附件不包含。客户端由 CI 重新生成，实际验证结果以新 tag 的 Actions 和 Release 附件为准。没有修改 DSH 本体，也没有修改 Deck 的并行工作。

## 用户可见结构

默认仅有一行，后续调用更新数字，不自动展开：

```text
▸ 用了 18 个工具
```

用户展开总数后，内部列表仍逐项收起：

```text
▾ 用了 18 个工具
  ▸ 读取 · inkos/packages/cli/src/core/pipeline/runner.ts
  ▸ 读取 · inkos/docs/incremental-chapter-processing.md
  ▸ 运行命令 · 同步真实条款值的夹具修正并核验
```

单项展开后直接显示命令／参数和输出区域，带复制及必要的分页按钮；不再把参数和输出各自做成额外折叠层。文件读取的常规路径、offset、limit 合为紧凑参数行；命令内容保留原样，不模拟终端执行或把日志文本当作新指令。工具失败在对应行标明，未知结果不当作成功。

## 分组与真实信息

- 原生工具节点通过公开 `ChatSnapshot.nodes.values()`、逐节点 `source()` 和宿主 Chat target 的订阅分组，不查询 DOM 拼接记录，不改宿主历史。
- 同一轮次中，气泡之间的连续工具只由一个节点呈现总数，其他节点沿用原空行标记。正文、用户输入、协作事件、交互卡片和轮次边界截断分组；隐藏思考不把每次调用拆回一条。PTC 子调用保留。
- 追加工具沿用原摘要位置；向前补页时，已存在的摘要节点仍在窗口中就继续使用它，避免用户已展开的组件被替换。
- 历史 ChatRows 仅合并连续同会话工具行；相同名称的不同调用保留。重复页只按会话、调用编号和已知调用序号更新同一调用，缺编号的记录各自保留。
- 文件标题来自真实参数的 `file_path`／`path`／`filePath`／`filename`，脚本用途只取 `description`／`justification`。没有说明时显示工具类别与原工具名，不从脚本内容推测任务。
- 只有明确记录的 Bot 工作目录才用于缩短路径，保留工作目录名；目录外文件保留全路径，不猜项目根。

## 读取与保护

外层折叠不发额外请求。原生节点展开总数时，通过既有 `extra-tool-list` 分页读取已脱敏短说明和路径，不为每个标题读取完整参数／输出；有界扫描最多 8 页。按调用编号、轮次和已知记录范围关联，存在歧义时不拼接别的调用。

单项展开才读取参数和输出，客户端最多 3 个请求并行、128 个排队；折叠、卸载或授权拒绝取消待发和进行中的读取。每个字段保留 128 Ki 字符显示预算，分页按 digest 和 offset 验证后原样拼接，不丢开头、不拼不同版本。授权拒绝或 HTTP 401／403 清空整组已读正文并卸载单项。

`extra-tool-list` 与增强历史行只新增可选 `filePath`；路径和短说明在服务器密钥库可用时先脱敏，再限制长度。密钥库锁定时不发送这两个字段。没有增加权限、写入能力或新的远程端点。

## 历史分页兼容

1.1.0 在要求显式 `throughSeq` 的宿主上，展开工具详情可能报 `throughSeq must be an integer greater than or equal to -1`。公开 `0.2.1-rc.5` 契约要求此字段，`0.2.2-rc.1` 才允许省略。1.2.0 已改为读取真实截止序号并固定同次扫描切面；冷历史用非激活投影，不启动 Agent。空日志的 `-1` 只在宿主确实给出空截止点时使用。回归定义与验证状态见 [verification.md](verification.md)，当前 1.1.0 附件不会自动获得修复。

## 接口依据与验证限制

分组接口已对照仓库固定 harness 版本 `0.2.2-rc.1` 的公开声明读取核对：

- `@deepseek-ai/dsh-client-ui-chat` 的 `ChatSnapshot`、`ChatNodeStore`、`ChatConversationViewNode` 与 `ToolChatData`。
- `@deepseek-ai/dsh-client-ui-conversation` 的工具生命周期与只读 `ToolArgs` 声明。

这些声明用于确认现有插件接点，不代表用户实际宿主所有版本都已实机验证。本机仅进行语法、编码、锚点和差异检查；回归定义与 GUI 需由 CI／用户执行。新增定义见 `extra-tool-groups.test.js`、`extra-tools-ui.test.js`，现有 `tool-cells.test.js`、`extra-observability.test.js` 增补相关断言。

实机核对：连续调用至少 18 个工具，默认只显示一行；继续调用时只变数字；展开后两个不同文件路径能直接辨认；再展开脚本可见原命令与结果且可复制。期间追加调用、翻旧页、收起／重新展开、切换 Bot、撤销授权，确认没有自动展开、重复计数、旧正文恢复或额外执行。
